# Project: Apex Orion Website Rebuild

## What This Is
A clean, modern, professional multi-page website for "Apex Orion," a next-generation software development agency based in Faisalabad, Pakistan. The interface is engineered with Tailwind CSS and styled after a premium dark navy/deep-purple visual design featuring glowing accents, soft glassmorphism, and responsive interactive modules.

## Core Value
Present an immersive, responsive digital showcase that demonstrates Apex Orion's technical execution and visual precision to global clients.

## Context
We are rebuilding the frontend from scratch following a complete clean of the workspace, using Tailwind CSS and vanilla Javascript to avoid framework overhead while maintaining premium micro-animations.

## Constraints
- **Tech Stack**: Tailwind CSS, Vanilla Javascript, HTML5 (no external frameworks).
- **Environment**: Must run locally on a static file server.
- **Images**: Must map and load local assets correctly (`Logo.jpeg`, `Hero.png`, `robonic_robot.png`, `portfolio_allergenscan.png`, `portfolio_homez.png`, `portfolio_pos.png`).
